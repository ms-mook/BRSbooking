# BRSbooking — ระบบจองเวรหน่วยเจาะเลือดเก็บสิ่งส่งตรวจและ POCT

งานห้องปฏิบัติการเวชศาสตร์ชันสูตร โรงพยาบาลศรีนครินทร์

- **หน้าเว็บ**: โฮสต์บน Vercel (`public/`) — daisyUI 5 ธีม corporate + Tailwind CSS 4, ไอคอน Lucide, motion ด้วย CSS, รองรับมือถือ/แท็บเล็ต (เมนูล่าง, bottom sheet, ปัดเปลี่ยนเดือน, ติดตั้งเป็นแอปบนหน้าจอโฮมได้) และ PC แบบเต็มจอ
- **หลังบ้าน**: Google Apps Script (`apps-script/Code.gs`) เป็น JSON API
- **ฐานข้อมูล**: Google Sheet (แท็บ `Booking Data`, `Leave` เดิม + `Staff`, `Holidays`, `Settings` ที่ระบบสร้างให้)

```
หน้าเว็บ (Vercel) ──POST /api/gas──▶ api/gas.js (Vercel Function) ──▶ Apps Script /exec ──▶ Google Sheet
```

## ฟีเจอร์

**บุคลากร**
- เข้าสู่ระบบโดยค้นหา/เลือกชื่อ + PIN 4–6 หลัก (ครั้งแรก/หลังผู้ดูแลรีเซ็ต ใช้ PIN เริ่มต้น **1234** แล้วระบบบังคับให้ตั้ง PIN ใหม่ก่อนใช้งาน) — ไม่พบชื่อกด "ขอเพิ่มรายชื่อ" แล้วรอผู้ดูแลอนุมัติ
- การแจ้งเตือนสำเร็จ/เตือน/ผิดพลาดเป็น toast มุมจอ ปิดเองอัตโนมัติ ไม่บังการคลิก และไม่มีหน้าจอทึบระหว่างรอ server (แถบโหลดบางๆ ด้านบน + spinner บนปุ่ม)
- ปฏิทินรายเดือน แสดงเวรของตัวเอง วันเสาร์-อาทิตย์ และวันหยุดราชการ
- จองเวร: วันธรรมดาเลือกได้หลายช่วง (06:00-08:30, 08:30-12:30, 12:30-16:30, 16:30-สิ้นสุด) / เสาร์-อาทิตย์และวันหยุดราชการเลือกได้ 1 ช่วง (06:00-11:00, 06:00-12:00, 06:00-16:00, 06:00-สิ้นสุด) และ 1 เวรต่อวัน — กติกาเดียวกับระบบเดิม
- กันจองช่วงเวลาซ้ำในวันเดียวกัน (แม้ต่างห้อง) แก้ไข/ยกเลิกเวรของตัวเองได้
- ยกเลิกระหว่างรอบเปิด = "ยกเลิกการจอง" / หลังปิดรอบ = "ลาเวร" (ต้องระบุเหตุผล) บันทึกลงแท็บ `Leave`
- สรุปเวรของฉัน (รายเดือน / ล่วงหน้าทั้งหมด) พิมพ์หรือบันทึกเป็น PDF ได้ และ **เพิ่มลงปฏิทินมือถือ (.ics)** พร้อมเตือนล่วงหน้า 12 ชั่วโมง
- **จองหลายวันพร้อมกัน**: เปิด "เลือกหลายวัน" แตะวันที่ต้องการ แล้วจองห้อง/จุด/ช่วงเวลาเดียวกันในครั้งเดียว (วันที่ติดกติกาจะแจ้งเป็นรายวัน)
- หน้าแรกมีภาพรวม: เวรถัดไป, เวรเดือนนี้, สถานะรอบจองพร้อมนับถอยหลังวันปิดรับ
- ธีม **สว่าง / มืด / ตามเครื่อง** (ค่าเริ่มต้นสว่าง) และฟอนต์ Sarabun ที่เก็บในเว็บเอง
- เปลี่ยน PIN เองได้

**ผู้ดูแล** (ปุ่ม 🔑 ผู้ดูแลระบบ ในหน้าเข้าสู่ระบบ)
- ตารางเวรรวมรายเดือน กรองตามห้อง/จุด/ตำแหน่ง/วันที่/ชื่อ พร้อมสถิติ
- เพิ่ม/แก้ไขการจองแทนบุคลากร (ย้อนหลังได้ ระบบเตือนเมื่อจองซ้ำ) ลบ หรือบันทึกเป็นลาเวร
- Export Excel (ตารางเวร, สรุปรายวัน, สรุปรายบุคคล, ลา-ยกเลิก) และพิมพ์/PDF ตารางเวร
- ล้างข้อมูลเก่า (หน้าตั้งค่า): ย้ายรายการจอง/ลาที่เก่ากว่าวันที่เลือกไปแท็บ `Archive Booking` / `Archive Leave` ไม่ลบทิ้ง แนะนำทำทุก 2 เดือน
- จัดการบุคลากร: อนุมัติคำขอ เพิ่ม แก้ชื่อ/ตำแหน่ง (ปรับชื่อในรายการจองเดิมให้อัตโนมัติ) ระงับ รีเซ็ต PIN (กลับเป็น 1234 ให้ผู้ใช้ตั้งใหม่)
- จัดการวันหยุดราชการ: เพิ่ม/แก้/ลบได้ทันทีเมื่อรัฐบาลประกาศเปลี่ยนแปลง
- กรองตาม **ช่วงวันที่ (ข้ามเดือนได้)** ห้อง จุด ตำแหน่ง **ช่วงเวลา** ชื่อ แล้ว Export Excel / พิมพ์ ตามตัวกรอง
- 3 มุมมอง: **รายการ**, **ตารางเวร** (วันที่ × ห้อง × ช่วงเวลา พร้อมรายชื่อ) และ **ยังไม่จอง** (บุคลากรที่ยังไม่มีการจองในช่วงที่เลือก) — Excel มีแท็บ "ตารางเวร (ตาราง)" และ "ยังไม่จอง" ด้วย
- วันหยุดนักขัตฤกษ์: **ดึงจากปฏิทินวันหยุดไทยของ Google** (ตรวจแล้วกดบันทึก) และตั้งให้ **ปิดรับจองในวันหยุด** ได้ (ค่าเริ่มต้น: ปิดรับ, ผู้ดูแลยังเพิ่มให้ได้)
- ตรวจพบการจองซ้ำซ้อน (คนเดียวกัน วันเดียวกัน ช่วงทับกัน) แสดงป้าย "ซ้ำ" และกรองดูได้
- ตั้งค่า: เปิด/ปิดรับจอง **วันปิดรับจองอัตโนมัติ** เลือกเดือนที่เปิดให้จอง ข้อความประกาศ เบอร์ติดต่อ ให้วันหยุดราชการใช้กติกาแบบเสาร์-อาทิตย์หรือไม่ (ค่าเริ่มต้น: ไม่ — ตามข้อมูลจริงที่วันหยุดจองแบบวันธรรมดา)

## สิ่งที่ระบบเปลี่ยนใน Google Sheet

| แท็บ | การเปลี่ยนแปลง |
|---|---|
| `Booking Data` | คอลัมน์ A–L เหมือนเดิมทุกอย่าง เพิ่มคอลัมน์ M `ID` (รหัสอ้างอิงแต่ละการจอง) |
| `Leave` | คอลัมน์ A–L เหมือนเดิม เพิ่ม M–P: `ID`, `ประเภท`, `เหตุผล`, `ดำเนินการโดย` |
| `Staff` | สร้างใหม่ — ตั้งต้นจากรายชื่อที่เคยจองใน `Booking Data` (ยังไม่มี PIN = ใช้ PIN เริ่มต้น 1234) คอลัมน์ J `ต้องเปลี่ยน PIN` |
| `Holidays` | สร้างใหม่ — วันหยุดตั้งต้น ต.ค.–ธ.ค. 2569 และปี 2570 (อ้างอิงวันหยุดธนาคาร — ตรวจกับประกาศ ครม. อีกครั้ง) |
| `Settings` | สร้างใหม่ — ค่าตั้งต้น: เปิดรับจองทุกเดือน, วันหยุดใช้ช่วงวันธรรมดา |

> ⚠️ ติดตั้งและทดสอบกับ **สำเนา** ของชีตเสมอ อย่าผูกกับชีตที่ระบบเดิมใช้งานอยู่จนกว่าจะพร้อมย้ายจริง

## ติดตั้ง

### 1) Apps Script (หลังบ้าน)
1. เปิด Google Sheet ฉบับสำเนา → **ส่วนขยาย → Apps Script** (จะได้โปรเจกต์ใหม่ที่ผูกกับชีตนี้ ไม่ใช่โปรเจกต์เดิม)
2. ลบโค้ดตัวอย่างใน `Code.gs` แล้ววางเนื้อหาจาก `apps-script/Code.gs`
3. **การตั้งค่าโปรเจกต์ (⚙)** → ติ๊ก "แสดงไฟล์ Manifest appsscript.json" → วางเนื้อหาจาก `apps-script/appsscript.json`
4. **การตั้งค่าโปรเจกต์ → พร็อพเพอร์ตี้ของสคริปต์** เพิ่ม
   - `ADMIN_USER` = ชื่อผู้ใช้ผู้ดูแล
   - `ADMIN_PASS` = รหัสผ่านผู้ดูแล (ยาวและเดายาก)
   - `API_SECRET` = ข้อความสุ่มยาวๆ (ไม่บังคับ แต่แนะนำ — ต้องตั้งค่าเดียวกันบน Vercel)
5. เลือกฟังก์ชัน `setup` แล้วกด **เรียกใช้** → อนุญาตสิทธิ์ (ระบบจะสร้างแท็บ/คอลัมน์ให้)
6. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
7. คัดลอกลิงก์ที่ลงท้าย `/exec`

### 2) Vercel (หน้าเว็บ)
1. Vercel → **Add New → Project** → Import `tm-tmn/BRSbooking` (Framework Preset: **Other** — Build Command `npm run build` และ Output `public` ตั้งไว้ใน `vercel.json` แล้ว)
2. **Environment Variables**
   - `GAS_URL` = ลิงก์ `/exec` จากข้อ 1.7
   - `API_SECRET` = ค่าเดียวกับใน Script Properties (ถ้าตั้งไว้)
3. Deploy — ถ้าแก้ Environment Variables ภายหลังต้อง Redeploy

### อัปเดตโค้ดหลังบ้าน
วางโค้ดใหม่ใน Apps Script → **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ✏️ แก้ไข → เวอร์ชัน: เวอร์ชันใหม่ → ทำให้ใช้งานได้**
(ลิงก์ `/exec` เดิมใช้ต่อได้ — อย่ากด "การทำให้ใช้งานได้รายการใหม่" เพราะลิงก์จะเปลี่ยน)

## ความปลอดภัย
- PIN เก็บเป็น SHA-256 + salt ต่อคน (หลายรอบ) ไม่เก็บ PIN จริง และไม่รับ PIN เดาง่าย (1234, 0000, 1212 ฯลฯ)
- ใส่ PIN ผิด 5 ครั้ง ล็อกเฉพาะบัญชีนั้น 15 นาที ล็อกซ้ำเวลาเพิ่มเป็นเท่าตัว (สูงสุด 6 ชั่วโมง) — การล็อกผู้ดูแลผูกกับชื่อผู้ใช้ที่พิมพ์ คนที่ไม่รู้ชื่อผู้ใช้จริงจึงล็อกบัญชีผู้ดูแลไม่ได้
- PIN เริ่มต้น 1234 (แก้ได้ที่ `CONFIG.DEFAULT_PIN`) ใช้ได้เฉพาะบัญชีที่ยังไม่ตั้ง PIN หรือถูกรีเซ็ต เข้าแล้วจอง/ยกเลิกไม่ได้จนกว่าจะตั้ง PIN ใหม่ (server บังคับ) และห้ามตั้ง PIN ใหม่เป็น 1234 — ควรให้ทุกคนเข้าระบบตั้ง PIN ของตัวเองโดยเร็ว เพราะระหว่างนั้นใครรู้ 1234 ก็เข้าแทนได้ ผู้ดูแลดูได้ในหน้าบุคลากร (ป้าย "PIN เริ่มต้น")
- Content-Security-Policy ไม่อนุญาต script ภายนอก/inline, X-Frame-Options, HSTS (ตั้งใน `vercel.json`)
- Session อายุ 6 ชั่วโมง เปลี่ยน/รีเซ็ต PIN หรือระงับบัญชีแล้ว session เดิมใช้ไม่ได้ทันที
- เรียกได้เฉพาะฟังก์ชันในรายการ `API_` ข้อมูลที่ขึ้นต้นด้วย `= + - @` ถูกบันทึกเป็นข้อความ (กันสูตรแทรก)
- รหัสผู้ดูแลอยู่ใน Script Properties เท่านั้น ไม่มีในโค้ด/GitHub

## พัฒนาและทดสอบบนเครื่อง
```bash
npm install
npm run dev     # http://localhost:3000 ใช้ Apps Script จำลอง + ข้อมูลตัวอย่าง (ผู้ดูแล admin / admin1234)
npm run build   # สร้าง public/app.css จาก src/styles.css (Tailwind + daisyUI)
npm test        # build + ทดสอบหลังบ้าน 31 ชุด + หน้าเว็บ 45 ขั้นตอน (PC, iPhone SE, Pixel 7, iPad mini) ภาพหน้าจออยู่ใน test/output/
FIXTURE_FILE=booking.json npm run dev   # ลองกับข้อมูลจริงที่ export จากชีต (ห้าม commit ไฟล์ข้อมูลจริง)
GAS_URL=https://script.google.com/macros/s/.../exec npm run dev   # ต่อ Apps Script จริง
```

## โครงสร้าง
```
apps-script/   Code.gs, appsscript.json      หลังบ้าน (วางใน Apps Script)
api/gas.js                                   Vercel Function ส่งต่อไป Apps Script
src/styles.css                               Tailwind + daisyUI (build เป็น public/app.css)
public/        index.html, app.js, app.css, config.js, manifest.webmanifest, icons/, vendor/ (lucide, xlsx)
.github/workflows/test.yml                   รันชุดทดสอบทุกครั้งที่ push
dev/           server.mjs, gas-mock.mjs, fixture.mjs   สำหรับพัฒนา/ทดสอบ
test/          api.test.mjs, e2e.mjs
```

## การทดสอบก่อน deploy
ทุกครั้งที่ push ขึ้น GitHub จะรันชุดทดสอบทั้งหมดอัตโนมัติ (แท็บ Actions) — บัคที่เคยแก้แล้วมีชุดทดสอบเฉพาะ (`[R1]`–`[R31]`) กันไม่ให้กลับมาอีก
แนะนำให้เปิด Vercel → Project → Settings → Git → **Deployment Checks** ให้รอผลทดสอบผ่านก่อน deploy ขึ้น Production
