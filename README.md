# BRSbooking — ระบบจองเวรหน่วยเจาะเลือดเก็บสิ่งส่งตรวจและ POCT

งานห้องปฏิบัติการเวชศาสตร์ชันสูตร โรงพยาบาลศรีนครินทร์

- **หน้าเว็บ**: โฮสต์บน Vercel (`public/`)
- **หลังบ้าน**: Google Apps Script (`apps-script/Code.gs`) เป็น JSON API
- **ฐานข้อมูล**: Google Sheet (แท็บ `Booking Data`, `Leave` เดิม + `Staff`, `Holidays`, `Settings` ที่ระบบสร้างให้)

```
หน้าเว็บ (Vercel) ──POST /api/gas──▶ api/gas.js (Vercel Function) ──▶ Apps Script /exec ──▶ Google Sheet
```

## ฟีเจอร์

**บุคลากร**
- เข้าสู่ระบบโดยค้นหา/เลือกชื่อ + PIN 4–6 หลัก (ครั้งแรกตั้ง PIN เอง) — ไม่พบชื่อกด "ขอเพิ่มรายชื่อ" แล้วรอผู้ดูแลอนุมัติ
- ปฏิทินรายเดือน แสดงเวรของตัวเอง วันเสาร์-อาทิตย์ และวันหยุดราชการ
- จองเวร: วันธรรมดาเลือกได้หลายช่วง (06:00-08:30, 08:30-12:30, 12:30-16:30, 16:30-สิ้นสุด) / เสาร์-อาทิตย์และวันหยุดราชการเลือกได้ 1 ช่วง (06:00-11:00, 06:00-12:00, 06:00-16:00, 06:00-สิ้นสุด) และ 1 เวรต่อวัน — กติกาเดียวกับระบบเดิม
- กันจองช่วงเวลาซ้ำในวันเดียวกัน (แม้ต่างห้อง) แก้ไข/ยกเลิกเวรของตัวเองได้
- ยกเลิกระหว่างรอบเปิด = "ยกเลิกการจอง" / หลังปิดรอบ = "ลาเวร" (ต้องระบุเหตุผล) บันทึกลงแท็บ `Leave`
- สรุปเวรของฉัน (รายเดือน / ล่วงหน้าทั้งหมด) พิมพ์หรือบันทึกเป็น PDF ได้
- เปลี่ยน PIN เองได้

**ผู้ดูแล** (ปุ่ม 🔑 ผู้ดูแลระบบ ในหน้าเข้าสู่ระบบ)
- ตารางเวรรวมรายเดือน กรองตามห้อง/จุด/ตำแหน่ง/วันที่/ชื่อ พร้อมสถิติ
- เพิ่ม/แก้ไขการจองแทนบุคลากร (ย้อนหลังได้ ระบบเตือนเมื่อจองซ้ำ) ลบ หรือบันทึกเป็นลาเวร
- Export Excel (ตารางเวร, สรุปรายวัน, สรุปรายบุคคล, ลา-ยกเลิก) และพิมพ์/PDF ตารางเวร
- จัดการบุคลากร: อนุมัติคำขอ เพิ่ม แก้ชื่อ/ตำแหน่ง (ปรับชื่อในรายการจองเดิมให้อัตโนมัติ) ระงับ รีเซ็ต PIN
- จัดการวันหยุดราชการ: เพิ่ม/แก้/ลบได้ทันทีเมื่อรัฐบาลประกาศเปลี่ยนแปลง
- ตั้งค่า: เปิด/ปิดรับจอง เลือกเดือนที่เปิดให้จอง ข้อความประกาศ เบอร์ติดต่อ และให้วันหยุดราชการใช้กติกาแบบเสาร์-อาทิตย์หรือไม่

## สิ่งที่ระบบเปลี่ยนใน Google Sheet

| แท็บ | การเปลี่ยนแปลง |
|---|---|
| `Booking Data` | คอลัมน์ A–L เหมือนเดิมทุกอย่าง เพิ่มคอลัมน์ M `ID` (รหัสอ้างอิงแต่ละการจอง) |
| `Leave` | คอลัมน์ A–L เหมือนเดิม เพิ่ม M–P: `ID`, `ประเภท`, `เหตุผล`, `ดำเนินการโดย` |
| `Staff` | สร้างใหม่ — ตั้งต้นจากรายชื่อที่เคยจองใน `Booking Data` (ยังไม่มี PIN) |
| `Holidays` | สร้างใหม่ — วันหยุดตั้งต้น ธ.ค. 2569 และปี 2570 (ตรวจสอบกับประกาศทางการอีกครั้ง) |
| `Settings` | สร้างใหม่ — ค่าตั้งต้น: เปิดรับจอง ทุกเดือน |

> ⚠️ ติดตั้งและทดสอบกับ **สำเนา** ของชีตเสมอ อย่าผูกกับชีตที่ระบบเดิมใช้งานอยู่จนกว่าจะพร้อมย้ายจริง

## ติดตั้ง

### 1) Apps Script (หลังบ้าน)
1. เปิด Google Sheet ฉบับสำเนา → **ส่วนขยาย → Apps Script** (จะได้โปรเจกต์ใหม่ที่ผูกกับชีตนี้ ไม่ใช่โปรเจกต์เดิม)
2. ลบโค้ดตัวอย่างใน `Code.gs` แล้ววางเนื้อหาจาก `apps-script/Code.gs`
3. **การตั้งค่าโปรเจกต์ (⚙)** → ติ๊ก "แสดงไฟล์ Manifest appsscript.json" → วางเนื้อหาจาก `apps-script/appsscript.json`
4. **การตั้งค่าโปรเจกต์ → พร็อพเพอร์ตี้ของสคริปต์** เพิ่ม
   - `ADMIN_USER` = ชื่อผู้ใช้ผู้ดูแล
   - `ADMIN_PASS` = รหัสผ่านผู้ดูแล (ยาวและเดายาก)
   - `API_SECRET` = ข้อความสุ่มยาวๆ (ไม่บังคับ แต่แนะนำ — ต้องตั้งค่าเดียวกันบน Vercel)
5. เลือกฟังก์ชัน `setup` แล้วกด **เรียกใช้** → อนุญาตสิทธิ์ (ระบบจะสร้างแท็บ/คอลัมน์ให้)
6. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
7. คัดลอกลิงก์ที่ลงท้าย `/exec`

### 2) Vercel (หน้าเว็บ)
1. Vercel → **Add New → Project** → Import `tm-tmn/BRSbooking` (Framework Preset: **Other**, ไม่ต้องตั้ง Build Command)
2. **Environment Variables**
   - `GAS_URL` = ลิงก์ `/exec` จากข้อ 1.7
   - `API_SECRET` = ค่าเดียวกับใน Script Properties (ถ้าตั้งไว้)
3. Deploy — ถ้าแก้ Environment Variables ภายหลังต้อง Redeploy

### อัปเดตโค้ดหลังบ้าน
วางโค้ดใหม่ใน Apps Script → **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ✏️ แก้ไข → เวอร์ชัน: เวอร์ชันใหม่ → ทำให้ใช้งานได้**
(ลิงก์ `/exec` เดิมใช้ต่อได้ — อย่ากด "การทำให้ใช้งานได้รายการใหม่" เพราะลิงก์จะเปลี่ยน)

## ความปลอดภัย
- PIN เก็บเป็น SHA-256 + salt ต่อคน (หลายรอบ) ไม่เก็บ PIN จริง
- ใส่ PIN ผิด 5 ครั้ง ล็อกเฉพาะบัญชีนั้น 15 นาที (ผู้ดูแลก็เช่นกัน)
- Session อายุ 6 ชั่วโมง เปลี่ยน/รีเซ็ต PIN หรือระงับบัญชีแล้ว session เดิมใช้ไม่ได้ทันที
- เรียกได้เฉพาะฟังก์ชันในรายการ `API_` ข้อมูลที่ขึ้นต้นด้วย `= + - @` ถูกบันทึกเป็นข้อความ (กันสูตรแทรก)
- รหัสผู้ดูแลอยู่ใน Script Properties เท่านั้น ไม่มีในโค้ด/GitHub

## พัฒนาและทดสอบบนเครื่อง
```bash
npm install
npm run dev     # http://localhost:3000 ใช้ Apps Script จำลอง + ข้อมูลตัวอย่าง (ผู้ดูแล admin / admin1234)
npm test        # ทดสอบหลังบ้าน 15 ชุด + หน้าเว็บ 27 ขั้นตอน (Playwright) ภาพหน้าจออยู่ใน test/output/
GAS_URL=https://script.google.com/macros/s/.../exec npm run dev   # ต่อ Apps Script จริง
```
